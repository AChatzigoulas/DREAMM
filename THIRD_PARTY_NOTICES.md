## Release gate

The installed science path requires the exact ProtDCal 4.5 JAR, ten companion JARs and associated configuration from the pinned local checkout. [The ProtDCal paper](https://pmc.ncbi.nlm.nih.gov/articles/PMC4432771/) states GNU GPL. The release record still lacks the applicable licence version and notices for those exact bytes, their matching Corresponding Source and build inputs where required, and a basis for distributing the extracted wCLQ weights. The DREAMM source archive contains [those weights](src/dreamm/data/wclq-weights.json). The CLI zipapp leaves the weights to the installed runtime. The local installer verifies the supplied assets by hash. [GPL source and object-code terms, if applicable](https://spdx.org/licenses/GPL-3.0-only.html).

| Option | Technical path | Publication condition |
| --- | --- | --- |
| Publish on the existing repository | Tag the reviewed tree and attach the curated ZIP, matching CLI zipapp and checksums. GitHub automatically supplies an archive of the tagged tree. Git clones carry reachable history. | Establish rights and provide the notices and corresponding source required for the legacy binaries, companion JARs, other conveyed assets and weight table. Custom attachments leave the automatic archives and clone contents in scope. [GitHub archives](https://docs.github.com/en/repositories/working-with-files/using-files/downloading-source-code-archives). |
| Distribute from a clean release location | Host the curated ZIP and CLI with matching source and checksums in a separate download location or a repository created from the curated tree without importing legacy Git objects. The original repository, files and tags can remain in place. The existing installer uses a user-supplied lawful checkout for the JARs. | Clear every included asset, including the weights. If the weights cannot be redistributed, omit them and separately qualify an installer that verifies the exact table from a lawful local source. Review the exact Java helper's dependency on the JAR for any applicable corresponding-source obligations. |
| Limit the automatic archive on the existing repository | Mark identified paths `export-ignore` in the tagged tree and verify the generated archive. | This only affects the archive snapshot. The files remain accessible through Git, so this does not resolve rights for publishing that repository. [Git archive attributes](https://git-scm.com/docs/git-archive#_attributes). |
| Keep the build for local qualification | Use the approved external installations and checksummed local assets under their terms. Preserve the existing history. | Keep the distribution decision open until the exact assets and intended release location have been cleared. |
