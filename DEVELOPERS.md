# DREAMM v1.1 developer guide

| Original source | Standalone source | Responsibility |
| --- | --- | --- |
| [`extract_features.py`](https://github.com/AChatzigoulas/DREAMM/blob/481055593c5676fb8f2a29c13e776782d772e527/dreamm/ML/extract_features.py) | [Acquisition and configured CLI](src/dreamm/configured.py), [intake](src/dreamm/cli.py), [mmCIF](src/dreamm_m1/mmcif_input.py) and [PDB](src/dreamm_m1/pdb_input.py) readers | Stage and fingerprint the original structure, retain all input models and select the first for prediction. |
| `featurizer` filter, mutation and preparation | [Historical conversions](src/dreamm/legacy_residues.py), [MoleculeKit filter](src/dreamm/modern.py), [two preparation passes](src/dreamm/modern_preparation.py) and [correspondence](src/dreamm/residue_mapping.py) | Apply the original table to selected polymer residues, retain N/CA/C/O during mutation and carry original IDs into the prepared structures and charges. |
| `featurizer` structural, sequence and neighbourhood features | [Pipeline](src/dreamm/modern_pipeline.py), [native tool calls](src/dreamm_m1/native_m1.py), [feature assembly](src/dreamm_m1/extraction.py), [Conservation](src/dreamm/trusted_science.py) | Preserve DSSP order, fixed HHblits search, FreeSASA/MSMS, ProDy, MDAnalysis and the original residue-number reduction for neighbourhood counts. |
| [`train_ProtDCal.py`](https://github.com/AChatzigoulas/DREAMM/blob/481055593c5676fb8f2a29c13e776782d772e527/dreamm/ML/train_ProtDCal.py) | [Adapter and identity join](src/dreamm_m1/identity.py), [470-column JVM integration](src/dreamm_m1/protdcal.py), [29-column wCLQ kernel](src/dreamm_m1/wclq.py), [Java finish helper](java/src/org/dreamm/m1/WclqFinish.java) | Run ProtDCal 4.5 with its original descriptor definitions, restore original precision and merge exactly 499 descriptor columns. |
| [Public `predict.py`](https://github.com/AChatzigoulas/DREAMM/blob/481055593c5676fb8f2a29c13e776782d772e527/dreamm/ML/predict.py) and retained web `all-res_testing.py` | [Inference](src/dreamm/modern_inference.py), [model loader](src/dreamm/model_compat.py), [legacy feature order](src/dreamm_m1/features.py) and [postprocessing](src/dreamm_m1/inference.py) | Verify the pinned model and reference, assemble 727 columns including 167 zeros, scale, infer and emit membrane calls with chain-local terminal/gap flags. |
| Web ensemble preparation, P2Rank and site analysis | [Reference checkpoint](src/dreamm/reference_export.py), [ensemble intake](src/dreamm/ensemble_source.py), [alignment and P2Rank](src/dreamm/ensemble_run.py), [filtering, ESSA and ranking](src/dreamm/ensemble_analysis.py) | Infer the reference once, followed by model-specific preparation and prediction, strict `<5 Å` interface association and versioned analysis. Frozen P2Rank artifacts retain their own model/profile provenance. |
| Web Chimera, DSSP and ExProSE branch | [Generation](src/dreamm/generation.py) and [Julia entry](src/dreamm/data/exprose_entry.jl) | Use the qualified runtime and `-w 0.4` to generate the requested additional conformations. Preserve all generated coordinates. Mark undefined optional PCA output appropriately. |
| Job scripting and result delivery | [Local supervisor](src/dreamm/trusted.py), [bounded-worker supervisor](src/dreamm/local.py), [coordinator client](src/dreamm/coordinator.py) and [exports](src/dreamm/exports.py) | Bind evidence to one attempt. Verify child exit and artifacts before completion. Emit PDB, CSV, PML and ZIP for single structures and ranked-site, XLSX and structural exports for ensembles. |

Preserve the pinned tool manifests under [`runtime/`](runtime/) and the scientific source manifest in [`core-sources.json`](core-sources.json). Source changes to an adapter are visible as overlays with previous fingerprints. The public webserver uses its separate containment/admission path. Configure trusted-local capacity only through the standalone CLI.
